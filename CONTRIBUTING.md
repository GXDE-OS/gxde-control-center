# 如何贡献 | Contributing Instructions

1. **将问题提交issues。**提交issues暂时没有固定格式，只需要提供一些合理的信息，例如当前的软硬件信息，
  执行了什么操作，你预计会发生什么，实际的现象以及复现问题的步骤。
  如果可以的话，试着做一些调试，并附上日志输入，方便问题定位。

2. 提交补丁完善代码。如果您希望引入重大更改或新功能，请首先在issues中进行讨论。

---

1. **Submit issues.** There is currently no fixed format for submitting issues. Simply provide some reasonable information, such as current hardware and software information, what operations you performed, what you expected to happen, the actual observed behavior, and steps to reproduce the issue. If possible, try to do some debugging and attach log output to facilitate problem locating.
2. **Submit patches to improve the code.** If you wish to introduce major changes or new features, please first discuss them in the issues section.
